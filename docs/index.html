See what the parent phone hears.

The live waveform gives a calm, glanceable view of recent audio activity and helps distinguish fresh quiet frames from a stalled stream.

Quiet uses cyan. Loud sound uses blue. The status label always reinforces the color, and the waveform advances only while fresh audio arrives.

Local by design.

Open Babyphone keeps its supported connection model simple and inspectable.

Network
Audio travels directly between paired phones on the same Wi-Fi or trusted local network.
Pairing
Scanning the child QR code transfers the pairing credential; mutual authentication is required before encrypted audio starts.
Infrastructure
No project-operated account service, cloud storage, analytics, or internet relay.
Source
GPLv3 source code, protocol details, releases, and development history are public on GitHub.
