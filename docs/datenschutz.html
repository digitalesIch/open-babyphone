Overview

This website (openbabyphone.org) is a static project website without registration, cookies, tracking tools, or advertising analytics. The website itself does not collect, store, or disclose personal data.

Hosting with GitHub Pages

This website is hosted through GitHub Pages. The provider is GitHub, Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA. When the website is accessed, GitHub automatically processes technical data such as the IP address, date and time of access, transferred data volume, referrer URL, browser, and operating system information in server log files.

The legal basis is Article 6 (1) (f) GDPR, the legitimate interest in providing and securing the hosting service. Further information is available in the GitHub Privacy Statement.

GitHub Releases API

The home page calls the public GitHub Releases API when it loads to display available app versions and download links. This creates a connection to api.github.com. GitHub may process technical access data such as the IP address, access time, browser information, and referrer.

The legal basis is Article 6 (1) (f) GDPR, the legitimate interest in showing available app versions and download links. If the request fails, the website links to the GitHub Releases page.

DNS resolution through OVH

The openbabyphone.org domain is resolved through OVH (OVH SAS, 2 rue Kellermann, 59100 Roubaix, France). OVH may process technical data for DNS resolution when the website is accessed. The legal basis is Article 6 (1) (f) GDPR. Further information is available in the OVH data protection information.

Your rights

You have the right to access (Article 15 GDPR), rectification (Article 16 GDPR), erasure (Article 17 GDPR), restriction of processing (Article 18 GDPR), and data portability (Article 20 GDPR). Contact the email address listed above.

Right to lodge a complaint

You have the right to lodge a complaint with a supervisory authority. The competent authority is the Saxon Data Protection and Transparency Commissioner: www.datenschutz.sachsen.de.
